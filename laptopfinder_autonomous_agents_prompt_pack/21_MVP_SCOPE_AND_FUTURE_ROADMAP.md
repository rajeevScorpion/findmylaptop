# MVP Scope and Future Roadmap

## MVP scope

Build the foundation for autonomous growth, but keep it controlled.

MVP includes:

- Agent settings and feature flags.
- Source adapter architecture.
- Manual source adapter.
- Amazon/Flipkart adapter scaffolds with real credential/API checks.
- Product candidate queue.
- Research Agent draft workflow.
- Blog topic and draft queue.
- Chip interaction logging and recommendation reasoning improvement.
- Central affiliate link resolver.
- Click tracking.
- Admin review screens.
- Safe scheduler.

MVP excludes unless already easy in current codebase:

- Fully autonomous publishing.
- Fully autonomous buying-deal pages.
- Complex AI agent framework.
- Ad optimization engine.
- Personalization based on sensitive data.
- Unapproved marketplace scraping.

## Future roadmap

### Roadmap 1 — Better product intelligence

- GPU wattage database.
- RAM/SSD upgradeability database.
- Service-center confidence by brand/city.
- Brand/store reliability signals.
- Historical price tracking if compliant.

### Roadmap 2 — Course/program matching

- Seed top colleges/programs.
- Map course software requirements.
- Generate course-specific laptop lists.
- Let users search by college/program.

### Roadmap 3 — Content growth

- Weekly blog calendar.
- Topic clusters.
- Program/course pages.
- Buying guides for parents.
- Comparison pages.

### Roadmap 4 — Chip personalization

- Better user preference memory.
- Saved shortlists.
- Follow-up reminders.
- WhatsApp/community handoff.
- Confidence coaching before purchase.

### Roadmap 5 — Monetization maturity

- Multi-source comparison cards.
- Contextual ads.
- Affiliate performance dashboard.
- A/B testing for CTA copy.
- Revenue attribution by content/topic/source.
